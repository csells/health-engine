# Make the first complete release migration-driven

The first complete Health Engine release will implement the foundational engine and every record type, analysis capability, reference-data path, Renderer, and adapter required to account for all `genetic-health` inputs and replace its substantive skills and reports. Broader health domains remain product direction rather than first-release checklist items until a concrete Source or workflow supplies an observable acceptance scenario, avoiding speculative interfaces that red-green TDD cannot validate through a real seam.
