# Make Analysis a typed dependency graph

Analysis will represent Findings, Guidance, exclusions, warnings, and policy decisions as typed nodes with explicit edges to the exact Facts, Corrections, rules, curated knowledge, and Reference Source versions that produced them. Freshness fingerprints are digests of this dependency manifest rather than substitutes for it, enabling deterministic explanation, impact analysis, semantic legacy comparison, and Analysis diffs while every Renderer remains a projection of the same complete value.
