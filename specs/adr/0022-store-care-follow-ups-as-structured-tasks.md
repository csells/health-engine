# Store care follow-ups as structured Care Tasks

When a Source says that a test should be repeated, a referral or appointment was requested, or a result is still expected, an agent will write a Care Task through Health Engine. The task records the requested action, due date or interval, requester, source location, and lifecycle state. Health Engine may then report the task as pending, due, overdue, completed, or awaiting a result. It will not invent a due date or silently treat an ordered test as completed merely because time passed.
