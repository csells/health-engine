# Manage structured health data in user-owned Workspaces

Health Engine will define and manage the SQLite Health Record inside a portable user Workspace that also contains agent-managed Sources and derived artifacts. The Rust library and CLI will initialize the database and provide the only supported interfaces for validating, writing, correcting, verifying, and querying Health Facts and for producing or retrieving Analyses. Agents and applications file original documents, perform fuzzy extraction and narrative work, and provide source references with extracted facts, but do not maintain parallel CSV or Markdown databases. Personal data stays in the explicitly selected Workspace and is never written to tracked or distributed project artifacts, the public reference-data cache, telemetry, or hidden global state.

The Workspace is a directory that can be backed up or moved as a unit. Agents and applications own the naming, routing, and preservation of original documents and genome exports. Health Engine exclusively manages the SQLite schema, transactions, migrations, structured facts, supplied source references, Evidence Assurance, discrepancies, care state, and Analysis history. It may read Source bytes to validate identity, size, media type, and aliases but does not copy, rename, move, delete, or interpret source files.
