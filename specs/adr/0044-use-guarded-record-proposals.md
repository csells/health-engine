# Use guarded Record Proposals for ordinary writes

Ordinary writes cross one deep seam: Health Engine validates a versioned, idempotent Record Change Set for an explicit Workspace, Subject, evidence origin and references, extractor, and expected revision into a non-mutating Record Proposal, then atomically applies that exact proposal if its hash and revision still match. Large imports such as genomes stream into a private hash-bound stage and seal a Proposal without changing canonical state; apply promotes it atomically, and crash cleanup removes abandoned stages. Additions, Corrections, Verifications, and Reconciliations share this transaction model; retries return the original Commit Receipt, each Extraction Run commits atomically, and Expungement remains a separate explicitly authorized interface.
