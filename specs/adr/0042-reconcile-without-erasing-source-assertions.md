# Reconcile duplicate observations without erasing Source assertions

Source identity is content-addressed: identical bytes form one Source with path aliases, while different documents remain distinct Sources. Moving an alias does not stale an Analysis while identical Source content remains available; changed or unavailable evidence invalidates dependent source Verification or raises an audit warning. Idempotency never deduplicates facts by value alone: the same command or Extraction Run returns its original receipt; a later run's exact same Source, location, and typed assertion is already present; a changed assertion becomes a Discrepancy or candidate; and equal assertions from different Sources remain separate immutable Facts. Equivalent Facts may be linked by Reconciliation and presented once in normal views, while conflicting Facts remain visible until explicitly addressed.
