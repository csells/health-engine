# Allow Operator-authorized Expungement as an append-only exception

Proposal validation and explicit Workspace and Subject identity are the primary defense against wrong-person ingestion, but an Operator may explicitly authorize Expungement for wrong-Subject data, accidental sensitive imports, or a deliberate privacy request. Health Engine physically removes affected PHI-bearing Facts, provenance, staged proposals, receipts, Analyses, Report Bundles, SQLite journals, and temporary artifacts under its control while retaining only a tombstone with a fixed non-PHI reason code. Agents may propose but never execute Expungement autonomously; the engine returns affected Source aliases and external-remediation instructions, while the Workspace host remains responsible for Source files, snapshots, and backups outside engine control.
