# Preserve semantic rather than textual report compatibility

Migration will account for every substantive legacy generated-report claim, but exact Markdown, HTML, wording, ordering, and formatting are not compatibility contracts. The structured Analysis is authoritative; each legacy claim must be reproduced, corrected, deliberately excluded with a reason, or retained as a Migration Candidate, while Renderers and skills may improve presentation and legacy filenames or broad sections may be preserved temporarily for cutover.
