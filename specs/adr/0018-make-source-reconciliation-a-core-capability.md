# Make source reconciliation a core capability

Every Health Fact extracted from a document will carry the agent-supplied reference to its preserved Source and, when available, the precise page, section, table, row, or quoted text that supports it. Health Engine will expose queries that let an agent retrieve all facts attributed to a Source, compare them against the original file, and record a Verification or Discrepancy through the same structured interface. This supports both routine double-checking and later audits after extraction rules or models improve. The engine may read Source bytes only to validate content identity and aliases; it does not interpret or manage the PDF itself and owns the provenance and audit workflow that makes agent review complete and durable.
